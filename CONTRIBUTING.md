# 🤝 Contributing to Hamza Boubakar Seddik's Portfolio & Engineering Ecosystem

Thank you for your interest in contributing to **Hamza Boubakar Seddik's** software engineering portfolio and enterprise developer toolset!

---

## 📌 Development Guidelines

1. **Language & RTL Support**: Always ensure all UI elements include `data-ar` and `data-en` attributes, keeping full compatibility with Cairo & Alexandria Google Fonts and RTL layout.
2. **Code Formatting**: PHP code must adhere to **PSR-12** standards.
3. **Database Security**: Use PDO prepared statements for all MySQL database queries.
4. **API Integration**: Keep the Gemini Flash API endpoint (`src/backend/ai-backend.php`) secure and performant.

---

## 🛠️ How to Submit Changes

1. Fork the repository on GitHub: `https://github.com/Hamza2024-CODE`.
2. Create a new feature branch: `git checkout -b feature/your-feature-name`.
3. Commit your changes with clear descriptions.
4. Open a Pull Request for review by **Hamza Boubakar Seddik**.
