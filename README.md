# 🚀 Hamza Boubakar Seddik — Enterprise Software Engineering Portfolio & Multi-Platform Systems

Welcome to the official portfolio and system management repository of **Hamza Boubakar Seddik** (حمزة بوبكر الصديق), Software Engineer & Multi-Platform Developer at the **Ministry of Vocational Training and Education (MFEP)** in Algiers, Algeria.

---

## 🌟 Key Platform Highlights

- **Arabic Native & RTL Support**: Dual-language architecture with 100% Arabic & English toggle, featuring Google Fonts Cairo & Alexandria.
- **Enterprise ERP & AI Backend Integration**: Integrated Gemini Flash API backend (`src/backend/ai-backend.php`) powering the **Hamza AI Assistant**.
- **Developer Tools Center**: 4 custom PHP developer utilities (`tools/php_converter.php`, `tools/php_writer.php`, `tools/php_syllabus.php`, `tools/omr_evaluator.php`).
- **Direct Admin Management**: Instant, password-free access to the redesigned administrative control panel (`admin`).
- **MySQL Database Driven**: Dynamic project catalog storing 13 enterprise projects (`portfolio_db.projects`).

---

## 🛠️ Technology Stack

- **Backend**: PHP 8.2, Laravel, C#, ASP.NET, Java, REST APIs
- **Database**: MySQL / MariaDB, Redis Caching
- **Frontend**: HTML5, Vanilla JavaScript, Tailwind CSS CDN, FontAwesome 6, Google Fonts Cairo & Alexandria
- **DevOps & Infrastructure**: Linux, Nginx, Google Cloud, Service Worker (PWA)
